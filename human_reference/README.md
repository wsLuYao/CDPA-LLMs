# Human-reference data / 人类参照数据

This directory is intentionally empty in the public repository. Participant-derived records are neither source code nor required for the demo pipeline.

公开仓库有意不附带任何参与者衍生记录。它们不是源代码，运行合成样例也不需要这些数据。

If you connect an approved dataset in your own deployment, keep it outside Git, document consent and retention, minimize fields, and verify that every item version and content digest matches the evaluated bank. See [`docs/DATA_POLICY.md`](../docs/DATA_POLICY.md).
