01

云服务商控制台

准备一台 Linux 云服务器

选择可通过 SSH 管理的云服务器，不要选虚拟主机。

正式使用建议 2 核 4 GB、40 GB SSD、5 Mbps 或更高，并分配公网 IPv4。

地域香港或靠近用户
系统Ubuntu 24.04 LTS 64 位
规格2 vCPU / 4 GB RAM
硬盘40 GB SSD+
带宽5 Mbps+
登录SSH 密钥优先
Ubuntu Server 官方文档 ↗创建后复制“公网 IPv4”
02

外部防火墙

只开放需要的安全组端口

协议端口来源作用
TCP22你的公网 IP /32SSH 管理
TCP800.0.0.0/0跳转与证书申请
TCP4430.0.0.0/0HTTPS 网站
UDP4430.0.0.0/0HTTP/3，可选
不要开放 8765，也不需要数据库端口。

8765 只在 Docker 内部网络使用。部署完成后，把 TCP 22 的来源收紧到你的管理 IP。

请按云服务商文档配置实例防火墙或安全组出站需允许访问互联网
03

域名控制台

添加一条 A 记录

记录类型A
主机记录assessment
记录值203.0.113.10
TTL600 或默认

根域名通常填写 @；子域名填写最左侧主机记录。除非服务器确实有公网 IPv6，否则不要添加 AAAA 记录。

在 Windows PowerShell 检查解析
nslookup assessment.example.com
在你的域名服务商控制台添加 A 记录解析可能需要 0—24 小时传播
04

SSH / 终端

连接服务器并获取源码

  1. 新建 SSH 连接主机填公网 IP，端口 22，用户名通常为 root。
  2. 克隆公开仓库把源码放到服务器的 /opt/cdpa 目录。
  3. 运行诊断逐行执行下面的命令。
连接服务器
ssh root@203.0.113.10
克隆并检查源码
git clone https://github.com/wsLuYao/CDPA-LLMs.git /opt/cdpa
  cd /opt/cdpa
  chmod +x scripts/*.sh
  ./scripts/doctor.sh
Ubuntu OpenSSH 文档 ↗命令没有回显密码属于正常现象
05

自动安装

安装 Docker Engine

部署包使用 Docker 官方软件源安装 Engine、Buildx 和 Compose 插件；如果服务器已有重要容器，请先备份并让管理员确认。

在 /opt/cdpa 中执行
sudo ./scripts/install-docker-ubuntu.sh
确认安装结果
docker --version
docker compose version
