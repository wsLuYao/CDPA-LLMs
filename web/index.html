    常见问题

    为什么示例题很少？

    公开仓库只提供无参与者数据的合成样例，用于验证题库格式、API 调用与报告流程。

    模型结果按什么顺序？

    预置名称按稳定顺序显示，其他模型随后按名称排列；排序仅影响展示，不改变数据。

    报告包含什么？

    包含质量概览、画像热图、差异维度、情境效应、重复稳定性、首选结构与模型相似度。

    为什么没有总分？

    四类题库测量含义不同，简单相加会制造未经验证的结论。

    关闭后还能继续吗？

    可以。重新启动平台，选择中断项目并重新填写各模型 API Key；已完成任务不会重做。

    专业统计在哪里？

    通俗报告底部提供“专业统计附录”，保留完整审计、公式和导出能力。

    请勿过度解读

    本工具用于研究 AI 模型的决策输出模式，不用于诊断真实个人，也不将“更像人类”解释为“更正确”。比较不同模型时，请保持题库、采样参数和重复设置一致。

    中断后恢复
